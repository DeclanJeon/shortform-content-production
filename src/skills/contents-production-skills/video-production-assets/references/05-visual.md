# 시각 구조·아트 디렉션

## 입력과 산출물
입력: 비트별 감정, 화면비, 레퍼런스

산출물: 시각 규칙, 룩 바이블, 장면별 대비 설계

## 실행 절차
1. 공간·선·형태·명암·색·움직임·리듬의 각 요소에 기본 규칙을 정한다. 이야기 변화와 연결할 핵심 요소부터 우선 선택하고 필요한 비교·전환에 맞게 범위를 정한다.
2. 시작·전환·클라이맥스의 대비/유사성을 설계한다. 색의 의미를 보편 감정 코드로 고정하지 말고 해당 작품의 반복과 맥락에서 구축한다.
3. 인물 실루엣, 의상, 소품, 배경 재질을 식별 가능하게 정한다. 실루엣과 작은 화면에서 정보 우선순위를 확인한다.
4. 메타포는 구체적인 시각 대응을 작성하고 관객이 추론할 단서를 준다. 설명 영상에서 메타포가 사실 관계를 왜곡하지 않게 한다.
5. 렌즈가 원근감을 독립적으로 결정한다고 쓰지 않는다. 카메라 위치·피사체 거리·화각을 함께 기록한다.
6. 시각 규칙의 예외를 전환 장면에 배치하고 이유를 적는다. 장식만 늘리는 룩 문장은 제거한다.

## 장소·키 비주얼의 사용 범위

같은 장소의 역방향/상태 변형이나 대표 키 비주얼에는 [실무 인계 R3](29-reference-driven-production.md#space-performance)를 적용한다(GUIDE-01 pp44–60). 장소의 외형 기준과 입출구·랜드마크·실제 광원 관계를 분리한다. 역방향은 좌우 반전 이미지가 아니며 빈 장소 마스터로 우연한 인물 전사를 피한다. 키 비주얼은 대표 순간·시선 중심·빛·재질/깊이를 설명할 뿐 정체성 시트·동작 콘티·검증된 3D 공간의 대체물이 아니다. 사건·신원·핵심 행동을 장식보다 먼저 확인한다.
