# 상태·인과·연속성 인계 (온디맨드 심화)

모듈 11(AI 인계)·21(생성 QA)·09(편집)·25(레퍼런스 분석)의 공통 인터페이스. 샷 사이에서 변한 상태와 유지해야 할 속성을 다음 모듈로 넘기는 **선택적** 인계 슬롯이다. 실행 순서·모션 비트·합성·카메라 제어·재시도 절차 자체는 각 모듈에 남아 있으며, 여기서는 재현하지 않는다. 프로젝트 스키마·전역 상태 DB·새 JSON 계약을 만들지 않는다 — 기존 shot/artifact ID와 버전에 행만 추가한다.

## 언제 연다

해당하는 조건의 행만 적용한다. 샷 자체의 변화뿐 아니라 앞선 샷에서 이어받은 후속 유지 의무도 활성 조건이다. 둘 다 없는 샷·시퀀스에는 이 모듈을 열지 않는다.

| 활성 조건 | 넘길 최소 계약 | 검사할 증거 위치 | 실행·검수 담당 |
|---|---|---|---|
| 대상이 누적 변화(익음·변색·젖음·낡음·조립) | 대상 ID · 변화 영역/속성 · 시작 상태 · 허용 변화 · 보존 영역/속성 · 끝 상태 · 후속 샷에서 유지될 범위 | 변화 전/후 구간과 후속 컷의 동일 대상 | 11 인계 → 21 QA |
| 원인 동작이 대상을 바꿔야 함(자르기·빛바래기·도포·제거) | 동작 → 대상 변화 → 잔류 결과 · 의도적 생략 여부 | 동작/접촉 구간과 결과가 보이는 후속 컷 | 11 인계 → 21 QA |
| 여러 시점의 같은 구조(앞/뒤/측면, 다른 각도의 동일 상자·제품) | 같은 면/특징/개구/접촉점의 대응표 · 가시/가림/미확인 | 각 시점에서 대응 특징이 실제로 보이는 프레임 | 25 분석 → 11 인계 |
| 두 대상이 서로 반응(눌림과 변형, 물건과 손, 사람과 사람) | 대상쌍 · 원인 행동 → 쌍방의 응답 · 접촉/분리 조건 · 후속 유지 | 상호작용 전체 구간 | 11 인계 → 21 QA |
| 시간 압축·생략(배속·타임랩스·몽타주·결과 컷) | 획득 방식 · 실제 경과시간/간격의 근거 · 생략 전 상태 → 생략 후 상태 | 원본 길이/촬영 로그와 편집 경계의 양쪽 상태 | 09 편집 → 11/21 |
| 정확한 레퍼런스 재현 요구(같은 구도·공간·광학 느낌을 복원) | 화면 정규화 기준점 · 측정/추정/미확인 구분 · 역추정 제약과 반증 조건 | 실제 프레임과 추가 시점, 도구 제약 | 25 분석 |

- **비적용(N/A)을 명시한다.** 새 변화와 상속된 유지 의무가 모두 없는 인터뷰·고정 제품 홀드에만 `상태 인계: N/A`로 닫는다. 앞서 바뀐 대상이 정지해 있거나 중간 컷에서 가려져도 선언한 유지 범위의 의무를 다음 해당 컷으로 넘긴다. 정밀 매칭 요구가 없으면 광학 역추정을 하지 않는다.
- **끝점만으로 전이를 증명하지 않는다.** 시작 상태와 끝 상태가 달라 보이는 것만으로는 원인 동작이 성립했다고 판정하지 않는다. 동작이 일어난 구간(손·도구와 대상의 접촉, 변화가 진행되는 프레임)과 끝 상태가 다음 샷 경계에서 실제로 유지되는지를 함께 본다. 구간을 검사하지 못했으면 해당 전이는 unverified다.
- **가림(occlusion)은 상태 역전이 아니다.** 카메라·다른 대상에 가려져 안 보이는 특징을 삭제·복원·반전으로 단정하지 않는다. 가림 전 마지막 관측 상태를 기록하고, 재등장 시점의 관측과 대조해 변화 여부를 판정한다. 재등장하지 않으면 미확인으로 남긴다.

## 인계 최소 슬롯

해당 조건의 필드만 쓰고, 나머지는 비워 둔다. 각 필드는 기존 ID·artifact 버전·실제 근거 위치(파일/프레임/타임코드/로그)에 묶는다.

- **대상과 범위**: 대상 ID(기존 prop/character/location/asset ID) · 변화가 적용되는 영역/속성 · 변화와 무관하게 보존되어야 할 영역/속성.
- **시작/끝 상태**: 관찰 가능한 기술(색·형태·온도·젖음·개수·위치 등)과 근거 위치. 끝 상태는 생성 요청의 끝 상태와 후속 샷의 시작 상태 양쪽에 연결된다.
- **후속 유지 범위**: 이 변화가 유효한 후속 샷/구간, 다시 리셋되는 조건(세척·교체·다른 대상), 리셋이 의도인지 오류인지. 바로 다음 컷뿐 아니라 문서화된 리셋까지 범위 안의 모든 해당 재등장·경계를 검사한다. 중간 가림은 의무를 지우지 않으며 관측 불가 구간만 미확인으로 남긴다. 액체 sheen, 물기, 먼지, 손자국처럼 남는 결과는 보이는 동안 계속 추적한다. 프레임 밖/가림은 리셋이 아니며, 자연 소실을 의도하면 표현·시간 경과의 근거와 새 상태를 명시한다.

요청된 동선/시퀀스가 복귀·종료까지 이어지면 관련 소품의 상태와 소유도 그 끝까지 닫는다. 기존 `끝 상태와 근거`와 `후속 유지 범위 / 리셋 조건`에 컷마다 들고 감/놓음/넘김/재장착을 연결한다. 브리프에 사용·이동·복귀 정보가 충분하면 설계 가능한 소품 처리를 `미정`으로 남기지 말고 일관된 선택으로 계획한다; 실제 제품 물성이나 승인 입력이 빠져 필요한 선택이 불가능할 때만 미확인 blocker를 기록한다.

- **원인 동작과 생략**: 결과를 만든 동작·접촉 대상, 화면에서 생략한 단계와 그 생략이 의도적이라는 표시. 의도 없는 생략은 21의 모션/시간 실패로 분류한다.
- **시점 대응**: 면·특징·개구·접촉점을 시점별로 연결한 대응표. 각 쌍은 관찰/추정/미확인으로 표시한다.
- **결합 응답**: 대상쌍과 각각의 응답(눌리는 손 → 변형되는 쿠션, 당기는 손 → 늘어나는 천). 응답이 일어나는 구간을 검사할 수 없으면 unverified로 기록한다; 구간을 검사했는데 요구된 응답이 실제로 빠져 있으면 21의 관찰된 실패로 판정한다.
- **시간 근거**: 획득 방식(연속 소스·고정 간격·몽타주·결과 컷), 실제 경과시간/간격의 근거, 생략 전후 상태. 경과시간·출력 길이만으로 실제 playback_rate나 촬영 간격을 확정하지 않는다(09 참조).
- **역추정 근거**: 화면 정규화에 쓴 기준점, 관찰과 추정의 분리, 가능한 카메라/렌즈 후보와 그것을 배제할 관측. 단일 이미지·크기 미상 조건에서 물리 렌즈·거리·센서 값을 확정하지 않는다(25 참조).

## 상태 전이 템플릿

`assets/state-transition-template.md`를 복사해 해당 행만 채운다. 모든 샷에 모든 슬롯을 요구하지 않으며, 빈 행은 삭제하거나 `N/A`로 둔다.

## 장르별 최소 예 (가상, 실제 생성/검수 결과 아님)

- **요리(누적 변화·원인 동작)**: 양파가 팬에서 갈색으로 변한다. 인계: 변화 속성=표면 색/투명도, 보존 속성=양파 조각 수·팬 위치, 원인 동작=저으며 볶는 구간. 의도적 생략(볶는 중간 20초 생략)을 표시하고, 다음 샷에서 팬 안 색이 시작 상태로 되돌아가지 않는지 검수한다. 볶는 구간을 검사하지 못하면 전이는 unverified다.
- **수선·의류(시점 대응·결합 응답)**: 재킷을 앞/뒤로 보여주는 두 컷. 인계: 같은 옷깃 바느질·단추 개구·안감 패턴의 대응표(관찰/가림/미확인), 손이 소매를 당길 때 소매가 늘어나고 손 위치도 따라가는 쌍의 응답. 가려진 뒷면 라벨을 없다고 단정하지 않는다.
- **뷰티(원인 동작·누적 변화·결합)**: 스포이드로 세럼 한 방울을 볼에 놓는다. 인계: 원인 동작=방울 접촉, 대상 변화=액체 위치·광택, 보존=피부 톤·머리카락·배경, 결합 응답=손끝 접촉에 대한 피부의 미세한 눌림. 잔류 결과가 다음 컷에서 사라지면 의도적 생략인지 리셋 오류인지 판정한다.
- **변화 없는 인터뷰(비적용)**: 고정 카메라로 말하는 사람. `상태 인계: N/A`, 변화·결합·시간 압축 필드를 채우지 않고 기존 정체성·오디오 검수만 적용한다.
- **정확한 레퍼런스 불일치 작업(가벼운 경로)**: 재현 정밀도 요구가 없고 일반적인 분위기 참조만 있는 경우, 시점 대응·역추정 슬롯을 `N/A`로 두고 기존 SSOT·연속성 인계만 사용한다.
